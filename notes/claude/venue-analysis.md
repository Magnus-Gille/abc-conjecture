# Venue analysis (preliminary — finalize after priority search lands)

Author: claude. Date: 2026-07-26.

Paper profile: short (est. 8–12 pp) rigorous note; elementary/classical
methods (LTE-style orbit arithmetic, pairwise coprimality, one application
of an effective linear-forms-in-logarithms theorem, Lucas sequences,
Wieferich-type lifts) + a reproducible computation; subject class 11D75
(abc), 11B39 (Lucas), 11J86 (linear forms in logs), 11Y50 (computation).

## Shortlist (order = recommendation, pending novelty verdict)

1. **arXiv math.NT first, regardless of journal.** Establishes priority,
   invites expert feedback before submission. Zero downside.
2. **INTEGERS: Electronic Journal of Combinatorial Number Theory.** Best
   fit: publishes exactly this genre (short, self-contained, elementary
   number theory with computational components), free/diamond OA,
   respectable editorial board, reasonable turnaround. Recommended
   primary target if the priority search returns "reduction is new,
   ingredients standard".
3. **The Fibonacci Quarterly.** The V_n(2,9)-at-dyadic-indices framing is
   squarely in scope; abc angle is a bonus for them. Good alternate.
4. **Journal of Integer Sequences.** Fits if we foreground the sequence
   d_j and its arithmetic; slightly weaker fit than 2–3 because the main
   theorem is analytic, not sequence-cataloguing.
5. **Ramanujan Journal / Bull. Aust. Math. Soc.** Stretch targets if the
   priority search shows the equivalence framing is genuinely absent
   from the literature AND we can add one more substantive result
   (e.g., generalizing from (1,8,9) to all opposite-parity seeds with a
   uniform statement). Otherwise overreach.

- AI policy of the chosen venue: no AI authors anywhere; disclosed AI
